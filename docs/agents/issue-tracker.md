# Issue Tracker

Issues are tracked on **GitHub**:
- **Repository**: [minhdevtry/orca-plugin](https://github.com/minhdevtry/orca-plugin)
- **CLI Tool**: `gh` (`gh issue list`, `gh issue create`, `gh issue view`)
- **Fallback**: Local markdown files under `.scratch/<feature>/` in this repo for offline / prototyping tasks.
