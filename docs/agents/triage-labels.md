# Triage Labels

This repository uses the 5 canonical triage labels from `mattpocock/skills`:

| Label | Role | Description |
| :--- | :--- | :--- |
| `needs-triage` | Initial review | Unsorted incoming work needing classification. |
| `needs-info` | Blocked on human | Missing critical context, spec details, or reproduction steps. |
| `ready-for-agent` | Ready to build | Requirements are clear, spec is complete (`/to-spec`), ready for agent execution (`/implement`). |
| `ready-for-human` | Ready for review | Code & tests complete, internal review passed (`/code-review`), awaiting human sign-off/merge. |
| `wontfix` | Out of scope | Work that will not be pursued. |

Active execution labels:
- `in-progress`: Agent is actively working inside a Git Worktree.
- `done`: Merged / completed.
